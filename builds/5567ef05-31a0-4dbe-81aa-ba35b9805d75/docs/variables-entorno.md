# Variables de entorno (valores de ejemplo, sin secretos)

| Variable | Ejemplo | Uso |
|---|---|---|
| QUARKUS_DATASOURCE_JDBC_URL | jdbc:postgresql://localhost:5432/banca | Conexión a PostgreSQL |
| QUARKUS_DATASOURCE_USERNAME | (definir en el entorno) | Usuario de BD |
| QUARKUS_DATASOURCE_PASSWORD | (definir en el entorno) | Contraseña de BD |
| CORS_ORIGINS | http://localhost:4200 | Orígenes permitidos |
| PORT | 8080 | Puerto HTTP |
| LOG_LEVEL | INFO | Nivel de log |
