# Variables de entorno

Backend: `DB_URL` (por defecto `jdbc:postgresql://localhost:5432/tarjetas`), `DB_USER`, `DB_PASSWORD` (obligatoria, sin valor por defecto), `CORS_ORIGINS`, `LOG_LEVEL`, `PORT`.

Frontend (Vite): `VITE_API_URL` (por defecto `http://localhost:8080`), `VITE_CLIENTE_ID` (UUID ficticio `00000000-0000-4000-8000-000000000001`; simula identidad, no apto para producción).

No guardar valores reales en el repositorio.
